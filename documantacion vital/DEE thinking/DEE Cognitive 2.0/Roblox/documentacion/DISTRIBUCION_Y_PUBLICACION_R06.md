# Dos modalidades de transferencia

**SDK**: `MANIFIESTO_DISTRIBUCION_SDK.json` selecciona sólo los 42 miembros canónicos de `sdk/0.1.1`. Incluye guías, contratos y ejemplos PREVIEW/conector; requiere Roblox Studio y un backend compatible autorizado para Native. No entrega un estado ni el runtime privado. Su integridad no acredita autonomía del ente.

**Investigación privada**: `MANIFIESTO_INVESTIGACION_PRIVADA.json` selecciona la carpeta activa, payload privado, laboratorio, estados, herramientas e instrucciones. No incluye el archivo externo ni credenciales. La transferencia requiere autorización de los titulares para todos los binarios/código/estados. No se establece ni amplía una licencia pública. `MANIFIESTO_ROBLOX.json` fija hashes y selección; el manifiesto no se incluye a sí mismo por hash.

El .gitignore es preventivo, no una revisión legal ni de secretos. Para un futuro repositorio público se usará la selección SDK expresa, después de revisar derechos. Nunca añadir todo Roblox por inferencia. El repositorio privado de investigación también debe excluir claves, conexiones, bases activas y temporales; estados congelados/binarios grandes requieren canales autorizados con hashes. Un repositorio privado no hace público un motor propietario ni concede derechos de redistribución.

El payload supera 100 MiB. GitHub bloquea archivos de más de 100 MiB en Git normal; usar un canal autorizado de artefactos o Git LFS cuando corresponda. Referencia: https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github . El manifiesto registra todos los miembros mayores de ese umbral. No se crea Git ni se sube nada en esta intervención.

Antes de publicar, revocar o rotar el token detectado previamente mediante el responsable autorizado; no se reproduce su valor ni se cambia aquí. La carpeta transferible no debe contener enlaces NTFS que arrastren históricos. Las rutas de procedencia en documentos congelados no son dependencias automáticas del instalador.
