API del compañero transporte_comprimido_R06.py:
- compressed_import(session,studio,raw_bytes,transfer_id,salida_nueva): sólo sube
  bytes privados a un Folder. Host Zstd3→base64; slots<=4664 caracteres. Servidor
  exige tamaño descomprimido<5.000.000, ratio<=1024, bytes y SHA de ambos niveles.
  Devuelve metadatos; todavía NO aplica World ni hace una consulta Native.
- import_apply_code(meta,expected,identity): genera la única llamada posterior a
  WorldAPI_R06.initialize, sin cambiar esa API. Es una mutación de mundo que Root
  envía una vez. No la reintenta si falta el recibo.
- compressed_export(...,raw_source_body,...): comprime una fuente congelada
  aprobada por Root, crea un nuevo Folder y obtiene el contenido por lecturas.
  Verifica SHA/tamaño/ventana Zstd y guarda FROZEN_RAW.json literal. La captura
  World actual se llama sólo tras el cierre del propietario y en BOUNDARY.
- frozen_hex_folder_source(...) permite leer un antiguo Folder hexadecimal ya
  completo sin consultar B actual. Se declara como transporte congelado0Native.
