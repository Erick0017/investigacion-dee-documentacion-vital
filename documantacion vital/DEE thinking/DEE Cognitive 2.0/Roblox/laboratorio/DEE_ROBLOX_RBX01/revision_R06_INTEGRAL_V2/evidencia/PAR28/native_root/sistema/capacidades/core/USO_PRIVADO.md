# Uso privado y reconstructivo

Proyecto DEE Universe / INVESTIGACION DEE. Autor del proyecto: Ivan Erick Tlaltecatl Morales.

Esta entrega contiene el instrumento oficial, recetas experimentales, código, estados esenciales y evidencia interna. Se prepara para recuperación y revisión privada; no se publica en Internet ni se describe como un paquete seguro para terceros.

Los avisos existentes del producto y de sus dependencias se conservan. No se inventa una licencia nueva ni se concede por este informe una autorización adicional de redistribución. La dependencia opcional NumPy no se copia desde la instalación de desarrollo: su identidad e instalación se documentan por separado.

El núcleo no sustituye automáticamente toda la historia documental ni autoriza borrar expedientes anteriores. Sólo los contratos aprobados en la recuperación limpia del ZIP exacto reciben una afirmación de sustitución operativa. El E1 de CPC9 y sus resultados nuevos pertenecen a otro expediente, no a una suma de los mundos históricos conservados aquí.
