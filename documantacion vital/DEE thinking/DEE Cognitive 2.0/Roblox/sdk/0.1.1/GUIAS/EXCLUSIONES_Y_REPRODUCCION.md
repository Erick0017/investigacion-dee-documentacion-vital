# Contenido excluido

Selección por allowlist de fuentes públicas congeladas, no copia recursiva del producto. Se excluyen RUNTIME_PRIVADO_LOCAL, configuraciones/conexiones privadas, escenas inyectadas, snapshots, SDK_PAIR, VIDA, ledgers, diarios/outboxes/colas, SQLite, DLL/PYD/WHL/EXE, imágenes y vídeo. No se incluyen el Manual global, kernel o fuentes privadas.

MANIFIESTO.json lista bytes/SHA256 de todos los miembros salvo él mismo: no tiene autorreferencia. El ZIP usa miembros ordenados, timestamps/permisos fijos y Deflate; la igualdad binaria se espera con los mismos inputs/interprete/zlib. La verificación limpia no abre Native, Studio, modelo, HTTP o SQLite. Fuentes locales y hashes no son un respaldo ejecutable del estado cognitivo.
