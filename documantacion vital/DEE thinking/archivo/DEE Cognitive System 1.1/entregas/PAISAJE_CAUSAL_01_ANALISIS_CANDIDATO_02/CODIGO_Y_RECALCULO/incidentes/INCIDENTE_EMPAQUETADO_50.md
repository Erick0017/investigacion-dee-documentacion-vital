# Corrección de clasificación del ensamblador

El primer candidato de carpetas se detuvo al confundir un diccionario de mundos inspeccionados pasivamente con las fichas `identity` de los factoriales simples. No se creó un ZIP válido ni se ejecutó física. Los datos y el archivo sólido verificado no se alteraron.

Se exige ahora la ficha explícita antes de clasificar una entrada como nuevo mundo simple; las inspecciones siguen siendo instrumentos sobre estados existentes. Se conserva el candidato incompleto y la revisión del código. Se genera un candidato nuevo, sin sobrescribir una entrega válida ni cambiar una conclusión científica.
