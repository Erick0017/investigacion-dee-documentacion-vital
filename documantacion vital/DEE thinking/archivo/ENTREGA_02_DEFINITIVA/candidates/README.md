# Candidatos de preintegración

Este árbol no forma parte de la API ni del catálogo estable. Sus ejecutables se
compilan con `candidates/CMakeLists.txt` y enlazan la biblioteca heredada
`../build/Release/lib/dee_thinking.lib`; no recompilan ni modifican el kernel.

- `h1_delay_position`: candidato CORE05 NRD05/NRH05, retardo relativo a
  identidad posicional de un detector.
- `h2_destination_repertoires`: candidato CORE07 C7H02, repertorios en fibras
  destino separadas y control de pérdida de identidad por solapamiento.
- `repair_core17`: reproducción candidata de reparación funcional desde una
  copia redundante que fue entrenada por separado; no es replicación adquirida.
- `accessibility`: contrato diagnóstico finito para separar existencia,
  historia y acceso; no exporta un builder universal.
- `../laboratory/preintegration`: contraste nuevo de tres experiencias y dos
  reutilizaciones posteriores con corte y sham comparables.

Las versiones `0.1.x-candidate` indican aislamiento deliberado. Promover cualquiera
de estos contratos exige una revisión separada del catálogo, composición,
snapshot y coste de recursos.
