Esta es una construcción real del producto, no una nueva campaña de capacidades
cognitivas. Incluye un WHL cp313/Windowsx64, biblioteca C++ instalable y fuentes
privadas. La ley v27 permanece idéntica.

Lea `../INFORME_TECNICO.md` para capacidad→mecanismo→evidencia→dominio;
`../VALIDATION_REPORT.json` para recuentos y límites; las tres matrices para
procedencia, coexistencia y modalidades. `INDICE_EVIDENCIA.json` enlaza primarios.

Evidencia principal:61pruebas heredadas y21nuevas instaladas;68trayectorias
diferenciales;32comparaciones de backends por versión; cuatro continuaciones
cruzadas;23suites C++ completadas en etapas (nueve afectadas repetidas al final).
Las historias adversas y fallos instrumentales permanecen disponibles.

K65 significa65formas opacas/dos clases direccionales, no65significados NSM.
Lectura remota, ausencia y pulso regulador adquirido son perfiles experimentales
finitos, separados del constructor consolidado.

El comprobante `VERIFICACION_FINAL_EXTERNA.json` está junto al ZIP y verifica
exactamente su hash mediante extracción, instalación y nuevas ejecuciones.
Sin ese comprobante no se infiere publicación verificada de un simple PASS interno.

La demostración se inicia con `../iniciar_4_5.ps1` o los comandos de `../LEEME.md`.
No hay conversación libre ni LLM oculto. La aplicación utiliza la API instalada.
Esta entrega es privada y contiene material reconstructivo; no es un export seguro
para revisión externa de terceros. Los documentos científicos definitivos no cambian.
