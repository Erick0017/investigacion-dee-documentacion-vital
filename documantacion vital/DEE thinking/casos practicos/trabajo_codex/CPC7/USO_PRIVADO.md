# Expediente privado y reconstructivo

Este CPC7 contiene código experimental, geometrías, interfaces, estados físicos y operativos, y un ejemplar del instrumento 4.0 congelado. No es una edición redactada para terceros. Sus hashes comprueban identidad, no conceden una licencia ni demuestran por sí solos las interpretaciones científicas.

No se autoriza desde este expediente ninguna difusión externa automática. Las consultas documentales públicas realizadas para seleccionar los comparadores no transmitieron archivos privados DEE. No se generó un paquete externo de CPC7.

El kernel y el producto no se modifican. Los adaptadores nuevos son preparaciones experimentales del usuario de la biblioteca; no una versión nueva del producto. Los avisos existentes están preservados bajo runtime/AVISOS. No se inventa una licencia del proyecto.

La base operativa se separa del auditor. Los generadores pueden presentar consecuencias observadas y exposiciones pedagógicas. Los participantes no usan los archivos EVALUATOR ni los resultados anteriores como memoria. El renderer presenta emisiones y medidas; las tablas de evaluación se calculan después de cada trayectoria.

Las fronteras de respaldo no son reinicios físicos. Las cargas recuperan estado, cola, canales, recibos y metadatos de protocolo. Una preparación nueva, una continuación y una rama diagnóstica se contabilizan por separado. Las intervenciones sobre copias no retornan a MAIN.

Los resultados adversos, los shams, las consultas ocupadas y las reparaciones técnicas permanecen en resultados/ y jobs/. Los archivos de fuente anteriores que se corrigieron durante la campaña se conservan como cortes identificados, no se presentan como el código final ejecutado en todos los ensayos.
