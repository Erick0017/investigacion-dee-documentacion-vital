# Iniciativa física, acceso a información y coexistencia: lectura de CPC7

La capacidad conseguida es una **pregunta física condicionada por una discrepancia**, seguida de recepción y uso dentro del mismo Runtime. Una historia AB/BA modifica el cuerpo relacional; su emisión en t5 se encuentra con un informe actual en t15. La transformación resultante encuentra una oportunidad común en t19: si la componente X se cancela, no viaja esa pregunta; si permanece, el portador alcanza una fuente y modifica una utilización posterior. El host agenda experiencias y oportunidades declaradas, pero no lee el error para elegir el puerto de respuesta.

Esta iniciativa es concreta: un mecanismo finito preparado actúa según el estado adquirido y la consecuencia presente. La oportunidad, las rutas y las alternativas fueron diseñadas por el investigador. Los ensayos no demuestran una política general que aprenda cuándo conviene preguntar ni un diagnóstico interno de cualquier incertidumbre.
