# Auditoría transversal efectiva

Se usaron fuentes recuperadas, índices y código; no se asumió que un informe
positivo bastaba. El núcleo compañero materializa por hash fuentes/configuración,
telemetría y evidencia terminal seleccionada de CPC3–7 y ambosCPC8; CPC1/2 se
recuperaron desde CPC3. `genealogia/CORE_MATRIZ_CAPACIDADES.json` identifica56
filas y sus fuentes, dominio, controles y límites. No es una lista exhaustiva
de todas las funciones concebibles ni una atribución conjunta a E1.

Se verificaron el WHL4.5, su extensión importada, versión y kernel. Se inspeccionó
su contrato ejecutable: Runtime, preparación research, sesiones, composición,
recibos, persistencia y observación. Las reproducciones físicas se distinguen de
las comprobaciones de API y de los recálculos puramente documentales. La copia
de código v27 conserva su hash oficial. Ningún producto/documento científico
original se editó; las nuevas recetas son de CPC9.

CORE06/07 se portaron mediante transición4.5 de arrays, con escrituras
instrumentales originales explícitas y NumPy externo declarado. CORE15–17 tienen
recálculos de sus primarios conservados, no una nueva reproducción íntegra de
todo su dominio. Lo mismo vale para compendios de Ingenierías, Procesos,
Procesamiento Nativo, observadores y Física: cada entradaD queda preservada,
sin elevarla por la presencia de un nombre de función. La matriz distingue esas
categorías y los recálculos de ejecuciones nativas nuevas.

Las conversaciones sólo aportan instrucciones/prompts o exportaciones realmente
localizadas. No hubo acceso directo inventado a conversaciones privadas de
ChatGPT ni lectura atribuida de fuentes sólo mencionadas. Las referencias
lingüísticas provienen del catálogo recuperado con hashes y bibliografía;
los accesos web de2026-10-17 son genealogía heredada, no consultas nuevas CPC9.

Se preservaron correcciones históricas importantes: el controlK65 no emparejado
puede aprender durante consultas; la revisión fuera de ruta no conservó64/64;
el respaldo requirió experiencias propias; U0 yK65 no se fusionan por compartir
biblioteca; F04/inspect no decide qué recordar. En CPC9, rechazos, falta de acceso,
actividad cero y respuesta equivocada no se colapsan en una sola etiqueta.

La campaña nueva toma mecanismos positivos como instrumentos de investigación,
no como soluciones semánticas completas. E1 empieza enT0 sin snapshot entrenado,
mantieneN67 y tiene una genealogía serial comprobable. Los mundos auxiliares,
intervenciones diagnósticas y reproducciones técnicas se inventarían como una
vida si se sumaran; por eso sus balances se mantienen separados.

El Core no es una copia sin pérdidas de26.5GB ni autoriza borrar originales.
Para cada contrato operativo se exige recuperación desde suZIP exacto con
dependencias declaradas; la prueba final y los hashes se mantienen fuera.
