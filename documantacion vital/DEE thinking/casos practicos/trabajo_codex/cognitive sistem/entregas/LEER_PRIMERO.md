# Entregas de colaboración

En el equipo de investigación, `ACTUALIZAR.bat` genera aquí `cognitive_sistem_colaborador.zip` y `ULTIMA_ENTREGA.json` con tamaño y SHA-256. Los ZIP nunca se incluyen dentro de sí mismos.

El colaborador recibe el ZIP por un medio acordado; la copia no se sincroniza automáticamente. Las actualizaciones incrementales sólo contienen archivos gestionados, no sus experimentos personales. Los candidatos y ZIP anteriores se conservan fuera del paquete nuevo como respaldo local.
