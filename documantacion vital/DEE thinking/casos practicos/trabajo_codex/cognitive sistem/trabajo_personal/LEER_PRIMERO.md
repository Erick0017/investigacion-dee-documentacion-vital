# Su trabajo

Aquí se crean las copias de vidas, estados completos, experiencias y resultados personales. Abrir un ente del catálogo no modifica el snapshot distribuido ni el original. Use identidades nuevas.

Las actualizaciones nunca escriben ni borran esta carpeta. El ZIP público de colaboración no exporta sus experimentos; respáldelos por separado. `INICIAR.bat gestor exportar SU_VIDA --salida trabajo_personal/mi_exportacion` guarda un estado completo mediante el gestor existente.
